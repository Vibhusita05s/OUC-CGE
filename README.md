# OUC-CGE

Early warning system for engagement drop prediction using **GRU + Attention**.

## Dataset
OUC-CGE (OUC Classroom Group Engagement Dataset) is designed for recognizing student group engagement in classroom environments using visual cues.

## Project Overview
This project predicts whether **student engagement will drop in the next 10 seconds** using:
- Feature extraction (SlowFast)
- GRU-based temporal modeling
- Attention mechanism for interpretability
